# ThriveJolt

ThriveJolt is a Cloud-based streaming-data platform, leveraging auto-scaling engine capabilities for scalable data processing.

With ThriveJolt, you get a lightweight tool that stays out of your way.

**What you get**

- ThriveJolt is a Cloud-based streaming-data
- platform, leveraging auto-scaling engine capabilities
- for scalable data processing

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/ThriveJolt.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

ThriveJolt is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
